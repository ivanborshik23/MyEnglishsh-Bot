# Telegram-бот "EnglishCard" 🇬🇧

Курсовая работа по курсу "Базы данных".
Бот помогает изучать английские слова методом карточек.

## 🗄 Схема Базы Данных
Ознакомиться со схемой (ER-диаграммой) можно по ссылке: 
[Посмотреть Schema.png](./Schema.png)

## 🛠 Технологии
- **Python 3.13**
- **Aiogram 3** (Асинхронный бот)
- **PostgreSQL** (База данных)
- **SQLAlchemy** (ORM)

## 🚀 Функционал
1. **Регистрация**: Автоматическая при старте.
2. **Личный словарь**: Каждому пользователю доступен свой набор слов.
3. **Обучение**: Система показывает слово, нужно выбрать перевод.
4. **Управление**: Можно добавлять свои слова и выбирать конкретное слово для удаления.
5. **Отказоустойчивость**: Реализована обработка исключений при работе с БД.

## ⚙️ Запуск проекта
1. Клонировать репозиторий.
2. Создать виртуальное окружение и установить зависимости:
   `pip install -r requirements.txt`
3. Создать файл `.env` с настройками БД и токеном.
4. Запустить: `python main.py`
